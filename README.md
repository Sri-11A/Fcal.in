A web-based financial calculator designed to simplify complex money calculations for everyday users, students, and professionals.

Key Features
✔ Loan Calculator - Estimate monthly payments, total interest, and amortization schedules
✔ Investment Growth - Project future value of investments with compound interest
✔ Savings Planner - Calculate how much to save regularly to reach financial goals
✔ Currency Converter - Convert between major world currencies (optional)
✔ User-Friendly Interface - Clean, intuitive design that works on all devices

🛠️ Technologies Used
Frontend: HTML5, CSS3, JavaScript

Hosting: GitHub Pages (free cloud hosting)
